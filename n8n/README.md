# n8n automation

`invoice-intake.workflow.json` (generated by `python n8n/build_workflow.py`) contains two chains:

```
A  New email (IMAP) -> split attachments -> POST DocSense /api/v1/integrations/inbound/   (async)
B  DocSense webhook -> verify HMAC -> document.processed -> append row to Google Sheets
                                   -> document.flagged   -> Slack alert (email alternative, disabled)
```

## Setup

1. **DocSense**: Settings -> API keys -> create a key for the workspace (shown once).
   Settings -> Webhooks -> add `https://<your-n8n>/webhook/docsense`, events
   `document.processed` + `document.flagged`; copy the `whsec_...` secret (shown once).
   For a local n8n on `localhost`, set `WEBHOOKS_ALLOW_PRIVATE=1` on the DocSense backend
   (outside dev the SSRF guard blocks private addresses on purpose).
2. **n8n** environment:
   ```
   DOCSENSE_URL=https://<docsense-api-host>
   DOCSENSE_WEBHOOK_SECRET=whsec_...
   NODE_FUNCTION_ALLOW_BUILTIN=crypto
   N8N_BLOCK_ENV_ACCESS_IN_NODE=false
   ```
   Run locally with `docker run -p 5678:5678 -e ... n8nio/n8n`.
3. Import the workflow (Workflows -> Import from file) and set the credentials the nodes ask for:
   IMAP mailbox, *Header Auth* (`X-API-Key: ds_...`), Google Sheets OAuth2, Slack OAuth2.
   Replace `REPLACE_WITH_SPREADSHEET_ID` and create a sheet tab **Invoices** whose first row has the
   column names used in *Append to Google Sheet*.
4. Activate it. Email an invoice to the mailbox: a row appears in the sheet once DocSense finishes
   processing; suspicious invoices additionally raise a Slack alert.

## Webhook contract

Headers: `X-DocSense-Event`, `X-DocSense-Delivery`, `X-DocSense-Timestamp`,
`X-DocSense-Signature: sha256=HMAC_SHA256(secret, "<timestamp>.<raw body>")`. Reject timestamps older
than 5 minutes. Deliveries are retried 3 times (30 s, then 5 min) and visible in Settings.

```json
{ "event": "document.flagged", "workspace_id": 1,
  "document": {"id": 7, "name": "inv.png", "status": "done", "needs_review": false,
               "overall_confidence": 0.93, "url": "http://localhost:5173/#/documents/7"},
  "extraction": {"vendor_name": "...", "ntn": "...", "invoice_number": "...", "total": 3540.0},
  "issues": [], "flags": [{"kind": "exact_dup", "severity": "high", "evidence": {"duplicate_of": 3}}] }
```

> Status: the workflow JSON is validated structurally by `backend/apps/integrations/tests/test_n8n_workflow.py`
> (unique node names, valid connections, every node reachable, no secrets). It was **not** imported into a
> live n8n instance here, so node `typeVersion`s may need a click-through on your n8n version.
